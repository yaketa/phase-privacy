プライバシーポリシー — Phase

最終更新日: 2026年8月4日

要約。Phase はいかなるデータも収集しません。アカウントもサーバーもなく、ネットワーク通信のコードを 一切持っていません。あなたが書いたものはすべて、あなたの iPhone の中に留まります。

1. 責任者

Phase は個人開発者 yaketa が制作しています。 連絡先: PHASE_SUPPORT_EMAIL

2. Phase が何を、どこに保存するか

Phase は以下をこの端末の中だけに保存します。あなたが作成した時間帯（名前・開始時刻・終了時刻・ その時間帯が通知を出すかどうか）、時間帯ごとに書いたメモ本文、添付した画像（アプリ専用の保存領域にコピーされます）、 そして通知にメモ本文を表示するかどうかの設定1件です。これらは端末のストレージに書き込まれるだけで、 どこにも送信されることはありません。

Phase はあなたの写真ライブラリを読み取りません。画像は Apple のシステム写真ピッカーで選択され、 これはアプリの外部で動作し、あなたが選んだ画像だけを Phase に渡します。

3. Phase がしないこと

Phase はあなたのデータを収集・送信・アップロード・同期・バックアップしません。解析ツール、広告、 クラッシュレポート、サードパーティ SDK、いかなる種類のトラッキングも入っておらず、アカウント登録もログインも ありません。ネットワーク通信のコードを含まないため、ネットワーク接続が一切なくても動作します。

4. 第三者への提供

Phase は誰に対してもユーザーデータを提供しません。提供すべきデータも、提供する手段も存在しないためです。 2点だけ明記しておきます。Phase の入手は Apple との取引であり、Apple 自身のプライバシーポリシーが適用されます。 また、このポリシーのページは GitHub Pages 上にあるため、閲覧すると通常の Web リクエストが発生し、 GitHub がこれを記録する場合があります（IP アドレスなど）。これはアプリではなく、この Web サイトの話です。

5. 通知

通知を許可した場合、Phase は各時間帯の開始時刻にローカル通知を表示するよう iOS に依頼します。通知は あなたの端末上で iOS がスケジュールします。プッシュサーバーは介在せず、当方にも第三者にも何も送信されません。 設定で「ラベルのみ」を選ぶと、メモ本文がロック画面に表示されなくなります。通知の許可は iOS の 設定 › 通知 › Phase でいつでも取り消せます。

6. データの保持期間と削除方法

あなたのデータは、あなたが削除するまで端末内に残ります。当方は何も保持していないため、当方の側に 保持・消去すべきものはありません。

  • 画像を1枚削除する: 設定 › 対象の時間帯 › サムネイルの ✕ をタップ
  • 時間帯を1件と、その画像を削除する: 設定 › 対象の時間帯 › この時間帯を削除
  • 追加・編集した内容をすべて元に戻す: 設定 › 初期設定に戻す
  • 完全にすべて削除する: ホーム画面から Phase を削除してください。iOS がアプリの保存領域を 添付画像ごと削除し、予約済みの通知も破棄します。

7. あなたの権利

お住まいの地域によっては、個人データへのアクセス・訂正・削除・処理への異議を申し立てる権利、および 監督機関へ苦情を申し立てる権利をお持ちの場合があります。Phase は当方にいかなるデータも送信しないため、 当方は何も保有しておらず、対応すべき対象が存在しません。そうではないとお考えの場合は PHASE_SUPPORT_EMAIL までご連絡ください。30日以内に回答します。 当方は個人情報を販売も共有もしません。

8. お子様について

Phase は13歳未満（EU/EEA では16歳未満）のお子様を対象としていません。年齢を問わず、 いかなるデータも収集しません。

9. セキュリティ

あなたのデータは Phase 専用のアプリコンテナ内にあり、iOS がアプリデータに適用する端末レベルの保護 （パスコードでロックされている間の端末暗号化を含む）によって保護されます。Phase は独自の暗号化を 追加しておらず、保護すべきサーバー側の構成要素も持ちません。

10. 本ポリシーの変更

本ポリシーを変更した場合は、更新版をこのアドレスに、新しい「最終更新日」とともに公開します。
