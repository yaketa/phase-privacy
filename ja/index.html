プライバシーポリシー — Phase

最終更新日: 2026年8月6日

要約。Phase はいかなるデータも収集しません。アカウントも、Phase 自身のサーバーもなく、あなたが書いたものをどこかへ送信することもありません。ネットワークに触れるのは、買い切りの購入を App Store が処理するときだけです（5章）。あなたが書いたものがこの iPhone の外に出る経路は、端末のバックアップなど、あなた自身が管理する iOS の機能だけです（2章）。

1. 責任者

Phase は個人開発者 yaketa が制作しています。 連絡先: phase.app.support@gmail.com

2. Phase が何を、どこに保存するか

Phase がこの端末に保存するのは、以下だけです。

  • あなたが作成したメモ — ラベル・表示時間（開始と終了）・本文・そのメモが通知を出すかどうか
  • 添付した画像（アプリ専用の保存領域にコピーされます）。コピーは画像そのものから作り直すため、元の画像が持っていた位置情報やカメラ情報 — GPS 座標、撮影日時、機種名やレンズ名 — は引き継がれません
  • 通知にメモの本文を表示するかどうかの設定1件
  • 買い切りの購入が解除済みかどうかの真偽値1件（5章）

これらは端末のストレージに書き込まれるだけで、Phase がどこかへ送信することはありません。iPhone を iCloud や パソコンにバックアップしている場合は、他のアプリのデータと同様に、Phase のデータもそのバックアップに含まれます。 iOS の設定で、Phase を iCloud バックアップの対象から外すこともできます。

Phase はあなたの写真ライブラリを読み取りません。画像は Apple のシステム写真ピッカーで選択され、 これはアプリの外部で動作し、あなたが選んだ画像だけを Phase に渡します。

3. Phase がしないこと

Phase はあなたのデータを収集・送信・アップロード・同期せず、Phase 独自のバックアップも行いません （2章で述べた端末のバックアップは iOS の機能であって、Phase のものではありません）。解析ツール、広告、 クラッシュレポートを送る SDK、その他のサードパーティ SDK、いかなる種類のトラッキングも入っておらず、 アカウント登録もログインもありません。 Phase 自身のネットワーク通信のコードはなく、買い切りの購入と復元（これは端末と App Store のやり取りです。5章）を除けば、ネットワーク接続が一切なくても動作します。

4. 第三者への提供

Phase は誰に対してもユーザーデータを提供しません。保存された内容が当方や第三者に届くことはなく、 提供する手段も存在しないためです。 2点だけ明記しておきます。Phase の入手と買い切りの購入は Apple との取引であり、Apple 自身のプライバシーポリシーが適用されます。 また、このポリシーのページは GitHub Pages 上にあるため、閲覧すると通常の Web リクエストが発生し、 GitHub がこれを記録する場合があります（IP アドレスなど）。これはアプリではなく、この Web サイトの話です。

5. 買い切りの購入

Phase はメモ2つまでは無料です。買い切りの購入「メモを無制限に」を1回行うと、この上限がなくなります。購入はすべて Apple の App Store を通じて行われます。

  • 決済を処理するのは Apple です。Phase があなたの支払い情報や Apple アカウントの情報を受け取ることはなく、App Store からアプリに伝わるのは「購入が行われた」という事実だけです
  • Phase の手元に残るのは、2章に挙げた「解除済みかどうかの真偽値1件」だけです。これはこの端末に保存されます
  • 購入そのものの記録（返金を含む）は Apple が保持し、Apple 自身のプライバシーポリシーが適用されます
  • 再インストールや機種変更のあとは、設定 › メモを無制限に › 購入を復元 から購入を呼び戻せます

6. 通知

通知を許可した場合、Phase は、通知をオンにしている各メモの表示開始時刻にローカル通知を表示するよう iOS に依頼します。通知はあなたの端末上で iOS がスケジュールします。プッシュサーバーは介在せず、当方にも第三者にも何も送信されません。既定では、通知にはメモのラベルと本文の冒頭が表示されるため、本文がロック画面に表示されることがあります。設定で「ラベルのみ」を選ぶと、通知にはラベルと時刻だけが表示されます。通知の許可は iOS の 設定 › 通知 › Phase でいつでも取り消せます。

7. データの保持期間と削除方法

あなたのデータは、あなたが削除するまで端末内に残ります。当方は何も保持していないため、当方の側に 保持・消去すべきものはありません。

  • 画像を1枚削除する: 設定 › 対象のメモ › サムネイルの ✕ をタップ
  • メモを1つと、その画像を削除する: 設定 › 対象のメモ › このメモを削除
  • 追加・編集したメモを削除して、最初の2つに戻す: 設定 › 初期状態に戻す
  • この端末からすべて削除する: Phase のアイコンを長押しし、「アプリを削除」を選んでください。iOS が アプリの保存領域を添付画像ごと削除し、予約済みの通知も破棄します。

8. あなたの権利

お住まいの地域によっては、個人データへのアクセス・訂正・削除・処理への異議を申し立てる権利、および 監督機関へ苦情を申し立てる権利をお持ちの場合があります。Phase は当方にいかなるデータも送信しないため、 アプリ内のデータを当方が保有することはなく、対応すべき対象が存在しません。唯一の例外はメールです。 ご連絡をいただくと、当方はあなたのメールアドレスと、本文に書かれた内容を知ることになります。これらは 返信のためだけに使用し、用件が終わり次第、やり取りは削除します。上記に関するご連絡は phase.app.support@gmail.com までお願いします。30日以内に回答します。 正式な請求のために当方の住所が必要な場合は、メールでお求めいただければお知らせします。 当方は個人情報を販売も共有もしません。

9. お子様について

Phase は13歳未満（EU/EEA では16歳未満）のお子様を対象としていません。年齢を問わず、 いかなるデータも収集しません。

10. セキュリティ

あなたのデータは Phase 専用のアプリコンテナ内にあり、iOS がアプリデータに適用する端末レベルの保護に よって保護されます。この保護は、この iPhone にパスコードを設定していることが前提です。Phase は独自の 暗号化を追加しておらず、保護すべきサーバー側の構成要素も持ちません。

11. 本ポリシーの変更

本ポリシーを変更した場合は、更新版をこのアドレスに、新しい「最終更新日」とともに公開します。

連絡先: phase.app.support@gmail.com
