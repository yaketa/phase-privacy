プライバシーポリシー — Phase

最終更新日: 2026年8月5日

要約。Phase はいかなるデータも収集しません。アカウントもサーバーもなく、ネットワーク通信のコードを 一切持っておらず、どこにも何も送信しません。あなたが書いたものがこの iPhone の外に出る経路は、 端末のバックアップなど、あなた自身が管理する iOS の機能だけです（2章）。

1. 責任者

Phase は個人開発者 yaketa が制作しています。 連絡先: PHASE_SUPPORT_EMAIL

2. Phase が何を、どこに保存するか

Phase がこの端末に保存するのは、以下だけです。

  • あなたが作成した時間帯 — ラベル・開始時刻・終了時刻・その時間帯が通知を出すかどうか
  • 時間帯ごとに書いたメモ本文
  • 添付した画像（アプリ専用の保存領域にコピーされます）。コピーは画像そのものから作り直すため、元の画像が持っていた位置情報やカメラ情報 — GPS 座標、撮影日時、機種名やレンズ名 — は引き継がれません
  • 通知にメモ本文を表示するかどうかの設定1件

これらは端末のストレージに書き込まれるだけで、Phase がどこかへ送信することはありません。iPhone を iCloud や パソコンにバックアップしている場合は、他のアプリのデータと同様に、Phase のデータもそのバックアップに含まれます。 iOS の設定で、Phase を iCloud バックアップの対象から外すこともできます。

Phase はあなたの写真ライブラリを読み取りません。画像は Apple のシステム写真ピッカーで選択され、 これはアプリの外部で動作し、あなたが選んだ画像だけを Phase に渡します。

3. Phase がしないこと

Phase はあなたのデータを収集・送信・アップロード・同期せず、Phase 独自のバックアップも行いません （2章で述べた端末のバックアップは iOS の機能であって、Phase のものではありません）。解析ツール、広告、 クラッシュレポートを送る SDK、その他のサードパーティ SDK、いかなる種類のトラッキングも入っておらず、 アカウント登録もログインもありません。ネットワーク通信のコードを含まないため、ネットワーク接続が 一切なくても動作します。

4. 第三者への提供

Phase は誰に対してもユーザーデータを提供しません。保存された内容が当方や第三者に届くことはなく、 提供する手段も存在しないためです。 2点だけ明記しておきます。Phase の入手は Apple との取引であり、Apple 自身のプライバシーポリシーが適用されます。 また、このポリシーのページは GitHub Pages 上にあるため、閲覧すると通常の Web リクエストが発生し、 GitHub がこれを記録する場合があります（IP アドレスなど）。これはアプリではなく、この Web サイトの話です。

5. 通知

通知を許可した場合、Phase は、通知をオンにしている各時間帯の開始時刻にローカル通知を表示するよう iOS に 依頼します。通知はあなたの端末上で iOS がスケジュールします。プッシュサーバーは介在せず、当方にも第三者にも 何も送信されません。既定では、通知には時間帯のラベルとメモの冒頭が表示されるため、メモ本文がロック画面に 表示されることがあります。設定で「ラベルのみ」を選ぶと、通知にはラベルと時刻だけが表示されます。通知の許可は iOS の 設定 › 通知 › Phase でいつでも取り消せます。

6. データの保持期間と削除方法

あなたのデータは、あなたが削除するまで端末内に残ります。当方は何も保持していないため、当方の側に 保持・消去すべきものはありません。

  • 画像を1枚削除する: 設定 › 対象の時間帯 › サムネイルの ✕ をタップ
  • 時間帯を1件と、その画像を削除する: 設定 › 対象の時間帯 › この時間帯を削除
  • 追加・編集した時間帯を削除して、最初の4件に戻す: 設定 › 初期状態に戻す
  • この端末からすべて削除する: Phase のアイコンを長押しし、「アプリを削除」を選んでください。iOS が アプリの保存領域を添付画像ごと削除し、予約済みの通知も破棄します。

7. あなたの権利

お住まいの地域によっては、個人データへのアクセス・訂正・削除・処理への異議を申し立てる権利、および 監督機関へ苦情を申し立てる権利をお持ちの場合があります。Phase は当方にいかなるデータも送信しないため、 アプリ内のデータを当方が保有することはなく、対応すべき対象が存在しません。唯一の例外はメールです。 ご連絡をいただくと、当方はあなたのメールアドレスと、本文に書かれた内容を知ることになります。これらは 返信のためだけに使用し、用件が終わり次第、やり取りは削除します。上記に関するご連絡は PHASE_SUPPORT_EMAIL までお願いします。30日以内に回答します。 正式な請求のために当方の住所が必要な場合は、メールでお求めいただければお知らせします。 当方は個人情報を販売も共有もしません。

8. お子様について

Phase は13歳未満（EU/EEA では16歳未満）のお子様を対象としていません。年齢を問わず、 いかなるデータも収集しません。

9. セキュリティ

あなたのデータは Phase 専用のアプリコンテナ内にあり、iOS がアプリデータに適用する端末レベルの保護に よって保護されます。この保護は、この iPhone にパスコードを設定していることが前提です。Phase は独自の 暗号化を追加しておらず、保護すべきサーバー側の構成要素も持ちません。

10. 本ポリシーの変更

本ポリシーを変更した場合は、更新版をこのアドレスに、新しい「最終更新日」とともに公開します。
